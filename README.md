Resolucion del ejercicio N°15 de la unidad 3 de programación 2.
Este programa encapsula la configuración de red de un enrutador asegurando que cualquier modificación de su dirección IP cumpla con un formato numérico y de rango válido (0 a 255 por cada octeto), ocultando al mismo tiempo los detalles y sockets internos de bajo nivel para exponer únicamente consultas de estado seguras.
